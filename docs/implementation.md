# 方案 G 扩展版实现说明

本说明对应扩展版网站和提交材料。详细关系模型、查询和实验见课程报告。

| 原方案任务 | 当前实现 |
| --- | --- |
| 三源采集 | OSV 三个生态导出、NVD 指定 CVE 和独立窗口样本、deps.dev 固定根版本与项目数据 |
| 包版本查询 | 包名部分匹配、逐版本严重度统计、确认命中筛选、公告和修复版本详情 |
| 编号与口径 | CVE/GHSA/PYSEC 别名对齐, 展示 NVD CPE 匹配项与原始记录 |
| 依赖清单 | 最多 100 项精确版本、TXT/POM、CSV，注册用户可保存摘要 |
| 传播与健康度 | 按下游包去重排名，Scorecard 分四组后统计每百版公告数 |
| 运维与复现 | 快照指纹、事务导入、管理员刷新统计、云端测试、真实与合成索引实验 |

当前范围包含 19,447 条 OSV 去重公告、66 条 NVD 记录和 20 个依赖根版本。CPE 详情保留产品匹配字段，完整配置树可沿 NVD 链接复核。Maven 数值版本可比较，复杂限定符依据 OSV 显式版本记录或标记为待核对。统计反映采集范围和更新时间。

原先三条 PyPI 公告的教学演示仍可从 `/sample` 进入。扩展版数据在 `data/library`，建表文件为 `sql/library.sql`。答辩材料使用扩展版的实际页面和同一次工作流中的数据库测量值。
